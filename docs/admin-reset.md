# 展示データの安全な初期化

管理画面は `/admin/reset` で開く。

## 有効化

サーバーの `app.env` に、HMAC鍵とは別の管理トークンを設定する。

```env
ADMIN_RESET_TOKEN=43文字以上のbase64urlトークン
```

トークンはソース、ブラウザストレージ、URL、ログへ保存しない。

## 操作手順

1. 管理トークンを入力し、「削除対象を確認する」を押す。
2. 通信記録、木、参加セッション、処理中ジョブの件数を確認する。
3. 影響確認へチェックを入れる。
4. 60秒有効の確認文を正確に入力する。
5. ブラウザの最終確認後、「展示データを初期化する」を実行する。

確認コードは一回限りで、誤入力した場合も再利用できない。

## 初期化されるもの

- 測定レコードと再配信用の観測履歴
- ノードごとの木の成長回数
- 参加者のクールダウン記録
- 待機中の測定ジョブ
- スマートフォンのコントローラーセッション
- 大型画面上の木、鳥、霧、手紙、紙飛行機、経路、カウンター

実行中のtracerouteプロセスを強制終了はしない。代わりに世代番号を更新し、
リセット前の処理が後から完了しても結果を登録・配信しない。

## 初期化されないもの

- ソースコードと設定
- 管理トークンとHMAC鍵
- traceroute、Cloudflare Tunnel、systemdの構成
