# 展示データのリセット

リセット画面は `/admin/reset` で開く。

「展示をまっさらにする」を押すとブラウザの確認画面が表示される。
確認後に実行すると、次の情報が消える。

- 測定レコードと再配信用の観測履歴
- ノードごとの木の成長回数
- 参加者ごとのクールダウン記録
- 待機中の測定ジョブ
- スマートフォンのコントローラーセッション
- 大型画面上の木、鳥、霧、手紙、紙飛行機、経路、カウンター

実行中の traceroute プロセスは強制終了しない。
代わりに世代番号を更新し、リセット前の処理が後から完了しても、
その結果を登録・配信しない。

リセットAPIは公開URLと同じオリジンからのリクエストだけを受け付け、
リクエスト本文に `confirmed: true` があることを確認する。
