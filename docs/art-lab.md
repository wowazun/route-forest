# Route Forest Art Lab

鳥と木の最終造形を、人間が本番統合前に比較するための検証環境。

公開ページ: `/art-lab`

## 比較する3方向と完成候補

### 折り痕 / FOLDED GROVE

通信を運ぶ鳥と木を、一枚の紙が折れて生まれた形として扱う。
手紙から紙飛行機への変化と最も連続性が高い。

### 筆脈 / INK VEIN

一本の筆線が鳥の羽ばたきから木の枝へ連続する。
遠目で柔らかく、有機的な印象が強い。

### 通信層 / SIGNAL CANOPY

鳥を伝播する波、木を蓄積する等高線として描く。
情報通信路という作品固有の主題との結びつきが最も強い。

### 折翼・筆脈 / FACET WING + INK VEIN

提示された6三角形の低ポリ鳥と、筆脈の木を組み合わせた完成候補。

- 鳥は非 indexed の6三角形、18頂点をそのまま保持する
- 左右の翼頂点だけをローカル前方軸まわりに最大±34°羽ばたかせる
- 頭側を明るく、尾・外翼・後縁ほど暗くする
- 飛行中は最大±30°の旋回バンクを加える
- 木は `ink-vein` の筆線、葉群、揺れを共有する

## 比較条件

各案は次の条件を共有し、造形以外を変えない。

- パレット
- 背景
- 風の補助線
- 飛行経路
- 飛行速度
- 木の位置
- 木齢
- 木の本数
- 霧の位置と濃度

## 人間の評価項目

1. 5メートル離れて鳥と木を識別できるか
2. 木の成長が訪問の蓄積として読めるか
3. 鳥がいない時間にも森がうるさくならないか
4. 別のゲームや企業ダッシュボードに見えないか
5. 種、霧、経路光と役割が競合しないか
6. 1920×1080で3羽・220本を表示して性能基準を満たせるか

## 統合条件

- 人間が三案のいずれか、または完成候補を選ぶ
- 鳥と木の両方を同じ方向で採用するか個別に決める
- `/display?simulation=unknown-three`で一人分の演出を確認する
- `/display?performance=1`で負荷基準を再計測する
- 現行の手続き図形をフォールバックとして残す

選択されるまで本番展示の鳥と木は変更しない。
