# Route Forest visual-style-guide v1

## 中心概念

**闇の中で、通信が育つ。**

情報通信路を地図やネットワーク図として説明せず、鳥が運び、木が記憶し、
見えない区間へ霧が生まれ、到着した情報が紙飛行機として残る現象として描く。

実装上の正本は `public/visual-style.js` とする。この文書と表示が食い違う場合は、
まずトークンを更新し、公開スタイルガイドと展示画面の両方で確認する。

## 色の役割

| Token | Value | Role |
|---|---:|---|
| `night` | `#0b252c` | 最深部の背景 |
| `nightLift` | `#12333b` | 光や風を受ける背景 |
| `paper` | `#e7eef0` | 紙、主要文字 |
| `mist` | `#9dbbc0` | 霧、補助線 |
| `leaf` | `#74a9a5` | 木、蓄積した記憶 |
| `seed` | `#d5a24b` | 鳥、種、新規の出来事 |
| `route` | `#b8ded5` | 観測できた経路の発光 |
| `fault` | `#c77968` | システム障害だけ |
| `ink` | `#17363d` | 紙素材の折り線 |

色は役割を越えて流用しない。特に `fault` を装飾に使わず、`seed` を一般的な
ボタン色にしない。

## 書体

- Display: 明朝体。作品名、章題、感情の入口に限定する。
- Body: ゴシック体。説明と操作文に使用する。
- Utility: 等幅体。状態、数値、英字ラベルに限定する。

## 形と線

- 大気・補助線: 1px
- 通常オブジェクト: 1.2px
- 鳥や到着経路など活動中の線: 2.2px
- 実画面上の最小線幅: 0.8px
- 角丸カードを形の主語にしない。
- 物体は輪郭の描き込みではなく、重心・向き・動きで識別する。

## 動き

| Motion | Duration |
|---|---:|
| 種の落下 | 720ms |
| 手紙から紙飛行機への折り変化 | 1350ms |
| 羽の漂流 | 4200ms |
| 経路発光 | 7500ms |
| 霧の基準寿命 | 8000ms |
| 紙飛行機の飛行 | 11000ms |

`prefers-reduced-motion` では因果関係を残したまま大幅に短縮し、常時反復する
動きを止める。

## 空間構成

- 木の位置を地理的位置へ対応させない。
- 同じ匿名ノードは同じ木へ戻す。
- 未観測区間を実線で接続しない。
- 霧は局所的かつ有限時間にする。
- 一つの経路演出の主役は一羽の鳥とする。
- 既定の同時飛行は3羽までとする。

## 素材方式の選択

- 手続き図形: 常に比較用の基準実装として残す。
- SVG Path: 輪郭改善が必要で、拡大縮小時の線幅を保てる場合。
- Sprite: 多数表示する短い反復アニメーションで、GPU負荷を下げられる場合。
- Rive: 手紙の折り変化など、状態遷移自体が主役でコード契約と一対一になる場合。
- Shader: 霧や風の連続場。Canvas代替を維持できる場合。

## 人間の承認地点

次の変更は、公開前に人間が実画面で承認する。

1. パレットの役割追加・変更
2. 鳥、木、手紙、紙飛行機のシルエット変更
3. 霧の最大面積・不透明度変更
4. 経路発光の強度・寿命変更
5. Rive、Sprite、Shaderの新規導入
6. 1920×1080での同時表示密度変更

承認時は `/style-guide`、`/display?simulation=unknown-three`、
`/display?performance=1` の三画面を比較する。
